    The daily challenges on the watch (Challenges › Daily). Each one pays XP when it completes; finishing all of them sends a game request (the three-card reward picker), once per player per day. The day resets at midnight UTC. Players get a changed set on their next login.

    Daily challenges

    Types marked tutorial only fire just during the new-player tutorial, so nobody can complete them afterwards. Activity types (Dodgeball wins, Quest games, ...) only count in that activity. With a different set each day, every day needs the same number of challenges.

    RecFlare CDN

    What cdn.recflare.net (the RecFlare server's public file store) holds, and pulling files from it into this server. It has no list of its files - it only answers for a name you give it - so look a file up by name, or scan for the room saves this server needs but doesn't have (the rooms that load empty, like Run The Block and My Little Monsters) and restore the ones RecFlare has. A restored room save works straight away. Room files are named like 9zwumqm1vehgto2fj12y2yq7e.room; avatar bundles like a1a2taim2pwp2g9wme612ji8l.assetbundle (Quest builds: quest/<name>).

    Look up a file

    RecFlare rooms and their files

A name that's taken here gets _RF added.

    DB Editor

    View and edit the server's databases directly (backups are on the Database tab). Pick a database and a collection, find a document, change its JSON and save. Changes are live immediately and there is no undo button - every save and delete is written to Data/db-editor-audit.jsonl with the document as it was before, so a mistake can be put back by hand. Passwords, tokens and keys show as (hidden) and are kept as they are when you save. Some data is also held in the server's memory, so a change there may only show after that part reloads or the server restarts.

    Economy

    Creator Earnings

    A maker gets 30% of what a buyer spends on their invention / custom clothing / room key / room currency / room consumable. Each sale pends 14 days and is paid on the first Sunday after that (00:00 UTC). Coach and the Importer never earn.

    Test in-game account creation

    While ON, launching the game from an admin-allowlisted IP shows an empty account picker, so the client creates a brand-new account in-game (Orientation: choose name, password). Turn it OFF to log into your own account again. Allowlisted IPs also skip the signup / login / device limits.
